# Changelog

## [0.6.0] - 2025-06-14

### Added
- Full-text conversation search with relevance ranking
- Mood tracking with sentiment analysis over time
- Habit detection from conversation patterns
- Export/backup all conversations and memories to JSON
- Knowledge graph with fact relationships
- Redis caching layer and rate limiting
- Plugin system for custom tools
- Smart context-aware reminders
- Smart context window pruning for long conversations
- MCP server for IDE integration
- Daily digest endpoint
- Seed knowledge script for bulk document ingestion
- Comprehensive test suite for all new features

### Changed
- Updated architecture for modular feature composition
- Enhanced API with 15+ new endpoints
- Improved README documentation
